Put it online

Step 1

Your own web host

Any web host can show a Shingle website: the one that came with your domain, your internet provider's web space, or a friend's server.

1. Build

Set SITE_URL in site.conf to your address, then run bash build.sh.

2. Upload what is inside dist

Your host gives you a folder for your website, often called public_html, www or htdocs. Copy everything that is inside dist into it, so that index.html sits directly in that folder.

  • With the host's file manager: log in to your hosting account, open the file manager, go to the website folder and upload the files.
  • With FTP: install FileZilla, connect with the FTP details from your host, and drag the contents of dist into the website folder.

3. Open your address

Your website is online. Each time you change something: build, then upload the contents of dist again.

Shorter addresses (optional)

Out of the box, links look like about/index.html, so the website also opens straight from your computer. On a web host you can switch to shorter addresses such as /about/: set LINKS="web" in site.conf and build again. Pages then only work through a web server, not with a double click.

The "page not found" page

Shingle makes 404.html. Many hosts show it for wrong addresses by themselves. If yours does not, look for "custom error pages" in your hosting settings and choose 404.html.
