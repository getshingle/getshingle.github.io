Free hosting with Cloudflare

Cloudflare Pages shows your website to the world, fast and free, with your own domain if you have one. All you need is a free account: drag your dist folder into the page, and you are online.

Once: put it online

  1. Make a free account on cloudflare.com.
  2. Run bash build.sh, so that dist holds your newest website.
  3. In the Cloudflare dashboard, open Workers & Pages, choose Create application, and then Drag and drop your files. Cloudflare changes its labels from time to time; look for "Pages" and "upload".
  4. Give the project a name, for example my-website. It becomes your address: my-website.pages.dev.
  5. Drag the dist folder into the upload area. When all files are uploaded, choose Deploy site.

After a minute your website is online at my-website.pages.dev.

Every time you change something

  1. Run bash build.sh.
  2. Open your project in Cloudflare and choose Create a new deployment, for production.
  3. Drag the dist folder in again and deploy.

Uploading by dragging takes up to 1,000 files of up to 25 MB each, which is plenty for most small websites. Large photos and videos are the usual reason to hit the limit; make them smaller first.

Your own domain

In your project, open Custom domains and add your domain. Cloudflare shows what to change at the company where you bought it. Set SITE_URL in site.conf to that domain and build again.

Or: let Cloudflare take it from GitHub

If you keep your website on GitHub (step 2), Cloudflare can take every new version from there by itself. Then you only build and push in GitHub Desktop; there is nothing to upload.

Decide before you start: a project made by uploading cannot be switched to GitHub later. For GitHub you make a new project; you can delete the old one afterwards.

  1. In Workers & Pages, choose Create application, then Pages and Connect to Git.
  2. Allow Cloudflare to read your GitHub account and choose the repository with your website.
  3. Leave the build command empty and set the build output directory to /. Your repository already holds the finished website, so there is nothing to build.
  4. Click Save and Deploy.

From then on, each push in GitHub Desktop updates the website within a minute.

Safer settings for browsers, and moved pages

The Cloudflare extension adds a _headers file with safe default settings, and a _redirects file that sends visitors from old addresses to new ones. Both work with uploading and with GitHub.

Shorter addresses (optional)

Cloudflare shows about/index.html at /about/ by itself. For links that look like that too, set LINKS="web" in site.conf and build again. Pages then only work through a web server, not with a double click on your computer.
