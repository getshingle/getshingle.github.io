Let the internet build it

So far you build on your computer and push dist. Instead, you can keep the whole shingle folder on GitHub and let the internet run bash build.sh. Then you can even edit a page on github.com, and the website updates itself.

1. Keep the whole folder on GitHub

In GitHub Desktop, add the shingle folder itself (not dist) as a repository and publish it. Shingle already tells Git to leave out dist, because the internet will make it.

2a. With Cloudflare Pages

Connect the repository as in step 3, but with these settings:

  • Build command: bash build.sh
  • Build output directory: dist

Cloudflare runs the same command you run at home, on every push.

2b. Or with GitHub Pages

GitHub can build and show the website itself, with a small instruction file called a workflow.

  1. On github.com, open your repository's Settings → Pages and set Source to GitHub Actions.
  2. Go back to the repository's main page and choose Add file → Create new file.
  3. As the file name, type .github/workflows/build.yml. Each / makes a folder.
  4. Paste this text into the big box: 
    name: Build the website
on:
  push:
    branches: [main]
  workflow_dispatch:
permissions:
  contents: read
  pages: write
  id-token: write
concurrency:
  group: pages
  cancel-in-progress: false
jobs:
  build:
    runs-on: ubuntu-latest
    environment:
      name: github-pages
      url: ${{ steps.deployment.outputs.page_url }}
    steps:
      - uses: actions/checkout@v6
      - run: bash build.sh
      - uses: actions/configure-pages@v6
      - uses: actions/upload-pages-artifact@v5
        with:
          path: dist
      - id: deployment
        uses: actions/deploy-pages@v5
  5. Click Commit changes.

The Actions tab shows each build; there you can also start one by hand with Run workflow. When it is green, your website is online at your-name.github.io/your-repository/. Shingle's links work at such an address too; set it as SITE_URL in site.conf.

The next time you open GitHub Desktop, click Pull origin, so the new file is on your computer too.
