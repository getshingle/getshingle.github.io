# Ember

A kitchen and wine bar: home, about and contact pages, a menu, a gallery,
reviews, opening hours, a map and a form to ask for a table. It uses the
`noir` theme and the menu, business, gallery, testimonials, faq, forms and
embed extensions.

The website builds it into `site-ember.zip`, a complete folder with everything
in it: unzip it, open a terminal in it and run `bash build.sh`. Connect the
booking form to a form service as the forms extension's README explains.
