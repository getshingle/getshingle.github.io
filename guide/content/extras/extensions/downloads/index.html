Extensions

Extension

Downloads

Files to download, such as price lists, forms, brochures and reports, listed with their type and size.

Download See it ↗

What it is for

Patient and enrolment forms, price lists, menus as PDF, reports and whitepapers, a press kit: everything people want to print or keep.

Add files

Put them into content/downloads/. A folder makes a group with a heading:

content/downloads/1_price-list-2026.pdf      → "Price list 2026", PDF, 120 KB
content/downloads/1_price-list-2026.txt      optional: a title and a description
content/downloads/2_forms/registration.pdf   in the group "Forms"

The title comes from the file's name; a number at the start sets the order and is not shown. A text file with the same name gives a better title on its first line and a short description below it.

On other pages

{{DOWNLOADS} shows the list on any page.

Add it

  1. Download extension-downloads.zip and unzip it. Move the folder downloads into the extensions folder of your website.
  2. Run bash build.sh. The first time, the build adds example PDFs in content/downloads/ and a Downloads link at the bottom of every page, and tells you so.
  3. Change the examples to your own and build again.

The extension's README, also in the download, explains every field and how to change the look.
