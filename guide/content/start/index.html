Get started

Your website in three steps

Do this once. After that, every change is the same: edit, build, look.

1. Download

Download Shingle

Double-click the zip. You get a folder called shingle.

2. Build

Open a terminal in the shingle folder and type:

bash build.sh
How do I open a terminal in a folder?
  • Mac: open Terminal (Cmd + Space, type Terminal). Type cd and a space, drag the shingle folder onto the window, press Enter.
  • Windows: install Git for Windows once. Then right-click inside the shingle folder and choose Open Git Bash here (on Windows 11, first Show more options).
  • Linux: right-click inside the folder and choose Open in Terminal.

3. Look

Open the new dist folder and double-click index.html. That is your website.

It does not work
  • "bash: command not found" on Windows: use Git Bash, not the Command Prompt.
  • "No such file or directory": the terminal is not in the shingle folder yet. Repeat step 2.
  • Anything else: read the last lines in the terminal. Shingle says what is wrong and what to do.
