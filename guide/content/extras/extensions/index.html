Download

Add an extension

  1. Download and unzip

    Download the extension and double-click the zip. You get a folder with the extension inside, for example blog, and for some extensions two more files, collection.sh and collection.css.

  2. Copy into extensions

    Move everything from that folder into the extensions folder in your shingle folder. If your computer asks whether to replace collection.sh or collection.css, say yes.

  3. Build

    Run bash build.sh. The first time, Shingle puts example content in content/blog/ and adds "Blog" to the menu in site.conf. It tells you what it added.

  4. Make it yours

    Change or replace the examples in content/blog/. The file README.md in the extension's folder explains every field.

Write a blog post

Each post is a file in content/blog/. Its name starts with the date and ends with the address of the post:

content/blog/2026-10-18_opening-day.html    → /blog/opening-day/

A post with pictures is a folder with the pictures next to the text:

content/blog/2026-10-18_opening-day/index.html
content/blog/2026-10-18_opening-day/cover.jpg    the picture on the blog page
content/blog/2026-10-18_opening-day/inside.jpg   a picture in the text

The post starts with a short header, then the text:

---
title: We are open
summary: One or two sentences for the blog page and for link previews.
cover_alt: Our new shop from the street
---
<p>After three months of work, the doors are open.</p>
<img src="inside.jpg" alt="The shop inside, with wooden shelves">

News works the same way. The team, careers and projects (portfolio) use a number instead of a date, which sets the order: 001_anna-berg.html comes first.

  • draft: true in the header keeps a post off the website. bash build.sh preview shows drafts, so you can look before you publish.
  • A post dated in the future appears with the first build on or after that day.

Switch one off

Remove the link from the menu

Delete its line from MENU (or LEGAL) in site.conf. Shingle adds the link only the first time, so it will not come back.

Switch an extension off for a while

Rename its folder so it starts with _, for example extensions/_careers, and delete its menu line. Your content stays in content/careers/; rename the folder back to switch it on again.

Remove an extension completely

Delete its folder in extensions/, its folder in content/ and its menu line.

Markdown needs cmark-gfm

The Markdown extension uses a small program to turn Markdown into HTML. On a Mac, install Homebrew and run brew install cmark-gfm; on Ubuntu, run sudo apt install cmark-gfm; on Windows, use WSL. Its README has the details. Without the extension, Shingle reads only .html and needs nothing extra.
