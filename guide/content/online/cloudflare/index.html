Free hosting with Cloudflare

Cloudflare Pages takes your website from GitHub and shows it to the world, fast and free. Each time you push in GitHub Desktop, it updates within a minute.

Once: connect GitHub

  1. Make a free account on cloudflare.com.
  2. In the Cloudflare dashboard, open Workers & Pages and create a new Pages project with Connect to Git. Cloudflare's labels change from time to time; look for "Pages" and "Git".
  3. Allow Cloudflare to read your GitHub account and choose the repository with your website.
  4. Leave the build command empty and set the build output directory to /. Your repository already holds the finished website, so there is nothing to build.
  5. Click Save and Deploy.

After a minute your website is online at an address like my-website.pages.dev.

Your own domain

In your Pages project, open Custom domains and add your domain. Cloudflare shows what to change at the company where you bought it. Set SITE_URL in site.conf to that domain and build again.

Without GitHub

Cloudflare can also take the folder directly: create a Pages project with Upload assets (sometimes called Direct Upload) and drag the dist folder into the page. You then upload again after every change.

Safer settings for browsers

The cloudflare extension adds a _headers file with safe default settings, and a _redirects file for pages that moved.
