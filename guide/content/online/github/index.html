Step 2

Keep it on GitHub

GitHub stores your website for free and keeps every version. Cloudflare can then take each new version from there and put it online, or GitHub can show it itself.

You will store only the dist folder, the finished website, on GitHub. Your shingle folder stays on your computer.

Once: set it up

  1. Make a free account on github.com.
  2. Install GitHub Desktop and sign in with that account.
  3. Run bash build.sh, so that dist exists.
  4. In GitHub Desktop, choose File → Add local repository and pick the dist folder inside shingle. It says this is not a repository yet: choose create a repository, then Create repository.
  5. Click Publish repository. Give it a name, for example my-website. Keep it private if you like; Cloudflare can read private repositories too.

Every time you change something

  1. Run bash build.sh.
  2. Open GitHub Desktop. It lists the changed files.
  3. Write a few words about the change in the box at the bottom left, click Commit to main, then Push origin.

Shingle empties dist on every build but keeps its hidden .git folder, so GitHub Desktop always sees exactly what changed.

Using your own domain with GitHub Pages instead of Cloudflare

GitHub can also show the website itself: in the repository on github.com, open Settings → Pages, choose Deploy from a branch, the branch main and the folder / (root). For your own domain, put a file called CNAME with your domain in Shingle's static/ folder, so every build keeps it.
