# Halo Studio

A small web studio: home, services, about and contact pages, projects, a blog,
news, a team of five, job openings and a privacy policy. It uses the `violet`
theme and the portfolio, blog, news, team, careers and privacy extensions.

The website builds it into `site-halo.zip`, a complete folder with everything
in it: unzip it, open a terminal in it and run `bash build.sh`.
