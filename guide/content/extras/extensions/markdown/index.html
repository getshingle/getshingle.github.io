Markdown

Write pages, posts and every other entry in Markdown, a simple text format, instead of HTML. It needs one small extra program.

Download See it ↗

Why Markdown?

Markdown is plain text with a few signs: ## A heading, **bold**, - a list item, [a link](/contact/). It is easier to write than HTML, especially for long articles.

You type

## Opening hours

We are open **every day**
except Monday.

- Breakfast until 11:30
- Lunch from 12:00

[Book a table](/contact/)

You get

Opening hours

We are open every day except Monday.

  • Breakfast until 11:30
  • Lunch from 12:00

Book a table

Install cmark-gfm first

The extension uses a small program, cmark-gfm, to turn Markdown into HTML:

  • Mac: install Homebrew, then run brew install cmark-gfm.
  • Ubuntu, Debian: sudo apt install cmark-gfm.
  • Windows: use WSL (Ubuntu inside Windows) from the Microsoft Store, then the Ubuntu command above.

If it is missing, the build stops and says how to install it.

Write in Markdown

Name the file .md instead of .html: content/about.md, content/blog/2026-10-18_my-post.md, or index.md in a folder. The header at the top stays exactly the same:

---
title: About us
description: One sentence for search results.
---
We are a small studio by the river.

![The studio from the street](studio.jpg "Our studio since 2015")

A picture alone on its line gets the text in quotes as its caption. Tables, values such as {{EMAIL}, and HTML for anything Markdown cannot do all work too. The example page that comes with the extension shows them all; delete the folder content/markdown when you no longer need it.

Add it

  1. Download extension-markdown.zip and unzip it. Move the folder markdown into the extensions folder of your website.
  2. Run bash build.sh. The first time, the build adds an example page, content/markdown/index.md, that shows everything Markdown can do, and tells you so.
  3. Change the examples to your own and build again.

The extension's README, also in the download, explains every field and how to change the look.
