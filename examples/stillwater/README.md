# Stillwater Yoga

A yoga studio: home and contact pages, classes with a page each, a weekly
schedule, prices with a monthly/yearly switch, teachers, reviews, questions
and a form for a free first class. It uses the `mint` theme and the services,
schedule, pricing, team, testimonials, faq, business and forms extensions.

The website builds it into `site-stillwater.zip`, a complete folder with
everything in it: unzip it, open a terminal in it and run `bash build.sh`.
